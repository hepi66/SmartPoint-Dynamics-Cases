# Offline Evidence

This directory is reserved for sanitized offline evidence screenshots of the SmartPoint case. No screenshots have been supplied yet; only this instruction file exists.

Use one primary screenshot per case by default. Capture the result described in section 6 of its case page, remove secrets, tokens, personal addresses, unrelated records and unnecessary authentication/billing details, then store the real image here and link it from that page. Use a clear English filename such as a case number and short result description. Do not create placeholder image files or links to images that do not exist.

Additional screenshots are useful only when they add significant evidence. For example, a configuration image cannot prove successful runtime execution. Copilot evidence must show the configured/blocked state until a real successful runtime test occurs. The optional Opportunity flow has no available result evidence while unimplemented.

When evidence arrives, record what it demonstrates and its actual capture date, update the case's evidence status in PROJECT_PLAN.md, and keep Demo Ready pending until navigation, restart instructions and the intended demonstration path have also been checked. Never invent a screenshot, successful test or missing configuration value.
